# Календарь звонков

Упрощённый сервис бронирования времени по мотивам Cal.com: владелец предлагает время для звонков, гость бронирует свободный слот.

## Language

**Владелец**:
Человек, чей календарь бронируют. В системе ровно один владелец.
_Avoid_: Хост, организатор, хозяин

**Гость**:
Человек, который бронирует слот для звонка. Не авторизуется, при брони указывает имя и email.
_Avoid_: Клиент, посетитель, пользователь

**Звонок**:
Единица бронирования — разговор фиксированной длительности (30 минут), который гость бронирует у владельца.
_Avoid_: Событие, встреча, консультация

**Слот**:
Конкретный 30-минутный интервал времени, доступный для бронирования (например, «Пн 10:00–10:30»).
_Avoid_: Интервал, окно, таймслот

**Бронь**:
Слот, зарезервированный гостем. Содержит имя и email гостя.
_Avoid_: Запись, резервирование, заказ

**Расписание**:
Шаблон рабочих часов владельца (ежедневно 9:00–18:00), из которого генерируются слоты.
_Avoid_: Доступность, график, рабочие часы
